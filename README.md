# board_galnew

一款以工人放置为核心的校园桌游。玩家扮演高中生，每枚时段棋代表自己在那个时段可以安排的一次行动。课程决定今天能动几次，公共行动格决定这些机会能用在哪里。

## 一天的行动

按上午、中午、下午、放学的顺序结算。正常上课占用上午和下午，每人起初有中午、放学两次自由行动。学业达到相应课程的免修条件，或为那节课打出翘课牌，就多获得那个时段的一次行动。同一节课最多释放一次行动。

每个时段，有行动的玩家轮流将自己的棋子放到一个开放格，立即结算。限额格满员后，后手要另选位置。比如器材室在午休和下午各开放一个相机借用名额，放学后有校刊采编活动。正常上课的玩家可以午休先借相机。午休另有安排的玩家，则要决定是否值得为下午的名额翘课。多出的棋子给玩家一次选择，器材仍然要和同学争。

## 场上的角色与好感竞争

角色组成公共牌库，同时翻开数名。每张角色牌有一条好感轨，所有玩家都能在同一条轨上推进，用各自颜色的标记记录位置，可以同格。任一玩家先到满格，就收下角色牌，收回这张牌上的所有标记，再翻开一名新角色补位。

三人首测暂用以下参数：

- 同时公开 3 张角色，每张写一项偏好，例如林禾看重交出校刊素材，方遥看重完成训练。放置并结算校园行动后，若满足角色偏好，可选一名符合条件的角色前进 1 格。每次放置最多推进一次。
- 好感从 0 到 4。每位玩家首次到 2 格立即得 1 分，先到 4 格的人另外收下角色牌，值 2 分。角色退场后，此前取得的分数保留。
- 按玩家行动顺序结算。新牌从下一名玩家的行动开始生效，牌库用尽则空位留空。终局只计算已取得的阶段分和角色牌分。

首测记录每局换了几张角色，以及有人接近满格时，其他玩家会争行动格、转投别的角色，还是继续做自己的项目。角色数量、轨道长度与奖励均可据此调整。
